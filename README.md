# 小桃的五笔

基于 Swift 和 Apple InputMethodKit 的 macOS 原生五笔输入法。

## macOS 输入法

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools（`xcode-select --install`）。无第三方运行时依赖。默认构建当前 Mac 架构，使用本地临时签名，适合本机使用；对外分发需另行 Developer ID 签名和公证。

```bash
./get-dicts.sh
./get-pinyin-dict.sh
./scripts/build-macos.sh
./scripts/install-macos.sh
```

安装到 `~/Library/Input Methods/Wubi.app`。首次安装后注销并重新登录，在「系统设置 → 键盘 → 文本输入 → 编辑 → + → 简体中文」中添加「小桃的五笔」。不需要辅助功能权限。仅构建时，产物位于 `build/Wubi.app`；双击 app 不会代替输入源注册。

词库沿用 [极点五笔 86 词库](https://github.com/KyleBing/rime-wubi86-jidian)，下载文件不提交到仓库。根目录下除 `pinyin_simp.dict.yaml` 和旧生成表以外的 `*.dict.yaml` 作为五笔来源，至少需要主词库 `wubi86_jidian.dict.yaml`。支持两列或带权重的多列 Rime 码表，重复词条去重。内置扩展词库更新后需重新构建；个人词库使用下述运行时数据目录。使用和分发词库时请查看上游的许可说明。

拼音使用 [Rime 袖珍简化字拼音词库](https://github.com/rime/rime-pinyin-simp)，通过 `./get-pinyin-dict.sh` 下载。拼音与五笔独立查询，不会混用候选。拼音候选右侧仅以浅色显示对应的五笔反查码，优先最短编码（简码），不显示剩余拼音。反查使用当前五笔词库（含合并词和用户词库），没有编码时不显示。拼音词库采用 Apache License 2.0，来源说明及许可随 app 打包在 `Resources/licenses`。

构建时只打包原始词库。输入法启动或重新加载时，由随 app 打包的独立 Swift 辅助进程读取内置和用户词库，生成合并索引；主进程只读映射紧凑索引文件，构建完成后辅助进程退出；运行时不依赖 Python，不改写 app 包或原始码表。查询索引用紧凑 UTF-8 字节与偏移量保存，不再重复保留完整字符串词表；合并后释放词频和组词临时数据，前缀缓存最多保留 4,096 个候选。完整合并报告逐条写入磁盘，进程内只保留统计及各类前 30 条示例。构建辅助进程退出后，解析、组词和报告的临时分配全部由系统回收；重新加载失败时保留原索引。映射建立后删除临时文件，映射在使用期间继续有效。

默认把拼音表中五笔没有的汉字词语补入五笔词库。按单字的最长编码生成词组码：两字各取前两码，三字取前两字首码和第三字前两码，四字及以上取第一、第二、第三及最后一字首码。单字多编码时优先最长码，再比较原权重和来源顺序；缺少单字编码或包含非汉字的词跳过。已有词不额外猜测新编码。

一至三码完全保留原候选顺序；四码候选统一按拼音词频排序，不混用两份词库不同尺度的原始权重。同一词多读音取最高词频，缺少词频视为零，同频保留原五笔顺序，新词不强制放在后面。

用户数据保存在 `~/Library/Application Support/Wubi/`：

| 路径（相对于用户数据目录） | 用途 |
| --- | --- |
| `Dictionaries/Wubi/*.dict.yaml` | 用户五笔词库，编码为 a–z，最长四码 |
| `Dictionaries/Pinyin/*.dict.yaml` | 用户拼音词库，多音节用空格分隔；新增词也参与生成五笔编码 |
| `settings.json` | 可选运行时设置 |
| `dictionary-merge-report.json` / `.md` | 本次合并的完整报告与摘要 |
| `dictionary-load-issues.log` | 跳过的坏文件、设置错误和报告写入问题 |

目录首次启动自动创建。可从输入法菜单选择「打开用户词库目录」。将 Rime 格式的 `*.dict.yaml` 放入对应目录后，点击「重新加载词库」即可生效，无需编译或重启；加载成功、部分文件有误或加载失败均通过系统通知提示。删除或修改用户词库后同样操作；坏文件会跳过，不影响有效的内置词库。若没有任何有效五笔词条，重载会失败并保留上次可用索引。

五笔用户词库示例（词语、编码、权重之间使用 Tab）：

```text
---
name: user_wubi
...
自定义词	tpyy	100
```

拼音用户词库同样使用上述文件头，词条可以写成 `自定义词<Tab>zi ding yi ci<Tab>10000`。内置词库先读取，用户文件按文件名排序后追加，同词同码去重。

需要关闭拼音词补入五笔时，在用户数据目录的 `settings.json` 写入以下内容，再点「重新加载词库」：

```json
{"mergePinyinIntoWubi": false}
```

删除该设置或改成 `true` 可恢复合并。设置跨重启和重新构建保留。

| 按键 | 功能 |
| --- | --- |
| 小写 a–z | 输入五笔编码 |
| 单独按左 Shift | 切换英文直输 / 上次使用的中文模式 |
| 单独按右 Shift | 切换拼音 / 五笔；英文模式下按右 Shift 进入拼音 |
| 空格 | 上屏当前选中的候选词，默认首选词 |
| 1–5 | 选择当前页候选词，每页最多 5 个 |
| 上下方向键 | 逐个切换候选词，到页边界时自动跨页 |
| `,` / `.` | 上一页 / 下一页候选词 |
| Backspace | 删除一个编码 |
| Escape | 取消当前编码 |
| Return | 原样输入编码 |
| 四码唯一候选 | 保留候选，按空格或数字选词上屏 |
| 无候选编码（五笔包含超过四个字母） | 保留全部预编辑文本，空格或回车原样上屏 |

候选窗目前支持键盘选词，不支持鼠标点击。Shift 大写字母作为英文预编辑文本输入，Caps Lock 与常用系统快捷键交给应用处理。暂未实现拼音反查及设置面板。

五笔和拼音均支持前缀候选：例如五笔输入 `im` 可提前看到「没有」并用浅色标出剩余编码 `de`；拼音输入 `zhongg` 可提前看到「中国」，剩余编码为 `uo`。精确候选保留原顺序并排在前面，补全候选按词频排列，同频时优先剩余编码较短的词，同一个词不重复显示。仍需手动选词，不自动上屏。

无精确匹配但有前缀匹配时，空格、数字和上下键均可选择补全候选；回车始终原样提交预编辑文本，左 Shift 可切到英文直输。无任何精确或前缀候选时才按原来的英文预编辑规则处理。用户词库重新加载后，前缀索引与缓存一并更新。

单独按下并松开左 Shift 进入英文直输，所有字符及编辑按键直接交给应用，不经过预编辑、不转换中文标点。再按一次恢复上次的五笔或拼音模式。单独按右 Shift 在五笔和拼音之间切换。切换时短暂提示「英」「五」（五笔）或「拼」；有未完成的预编辑文本时，先原样提交该文本。按住任一 Shift 输入大写或符号、组合快捷键不触发模式切换。

拼音模式支持全拼字词：输入 `nihao` 选「你好」、`zhongguo` 选「中国」；也可用撇号明确音节，如 `xi'an` 选「西安」。`v` 表示 ü，如 `nv` 输入「女」。候选按词频排列，使用数字或空格选词、上下键移动选择、逗号句号翻页；回车仍原样提交拼音。拼音不受五笔四码限制。这是直接接入该词库的字词查询，并非完整 Rime 引擎，暂不支持模糊拼音、简拼或词库之外的整句组词。

当前选中词深色显示，其余候选词为浅色。上下键逐个移动选择，空格确认选中词，数字键按当前页编号直接选词；回车仍提交原始编码。

候选窗和引号提示窗使用直角，并自动跟随系统浅色、深色模式更新背景和文字颜色。定位以完整屏幕为边界，允许覆盖 Dock 区域以贴近输入光标；下方超出屏幕时改在光标上方显示。

五笔模式下，所有字母都累积在编辑框的预编辑文本中，不因输入第五个字母而自动上屏。无候选或超过四个字母时隐藏候选窗，后续数字、撇号等英文字符也保留在预编辑文本中；空格或回车提交英文原文，该按键只用于确认，不额外插入空格或换行。提交后立即可以输入下一段五笔。退格后重新匹配候选，Escape 取消整段预编辑文本。

默认输入中文标点；存在有效候选时，先上屏当前页首选词，再输入标点；无候选时英文标点保留在预编辑文本中。Caps Lock 开启时保留英文标点，Command、Control、Option 快捷键不转换。

| 键盘字符 | 中文标点 |
| --- | --- |
| `, . ? ! : ;` | `，。？！：；` |
| `\` | `、` |
| `( ) [ ] < >` | `（）【】《》` |
| 双引号 / 单引号 | 交替输入 `“”` / `‘’`，切换应用或输入法后重置 |
| `^` / `_` | `……` / `——` |
| `$` / `~` / 反引号 | `￥` / `～` / `·` |

输入中文引号后，光标附近会显示「左」或「右」，单、双引号均适用，约 0.8 秒后消失。继续按键或切换输入法会立即关闭提示，不抢焦点，不向正文插入提示文字；英文预编辑中的撇号不提示。

有候选词时，逗号和句号优先用于翻页；需要输入中文逗号或句号时，先按空格或数字选词。无候选时仍保留标点转换与英文预编辑规则。左右键、Page Up/Down、`-` 和 `=` 不再用于翻页。输入小数、网址等英文内容时可开启 Caps Lock 或切换英文输入源。

修改代码或内置词库后，运行以下命令更新，无需注销。仅修改用户词库时使用菜单「重新加载词库」即可：

```bash
./scripts/reload-macos.sh
```

脚本先构建并校验完整的新 app，临时切换到备用键盘，按实际 PID 停止输入法进程，再替换 app、启动并验证原输入源已恢复。替换期间保留旧版本，失败时尝试回退并恢复输入源；从菜单更新失败时发送失败通知。运行前请先完成正在输入的编码；进程重启会清空未完成的输入。这是重启更新，不是进程内热加载。首次安装或修改输入源注册信息后，仍可能需要注销登录。

也可以在选中「小桃的五笔」时，点击菜单栏输入法菜单中的「重新构建并加载输入法」。菜单按钮会后台运行同一更新脚本，新版本启动并恢复输入源后发送「小桃的五笔重新加载成功」系统通知，无需点击关闭。通知是否显示受系统通知设置和专注模式影响。日志写入 `~/Library/Logs/Wubi/reload.log`。此开发功能依赖构建时的本机源码目录；目录移走后需在新位置重新构建安装。

卸载时先从系统设置移除输入源，再删除 `~/Library/Input Methods/Wubi.app`，注销登录。

运行回归测试（无需安装输入法，无需下载词库）：

```bash
./scripts/test.sh
```

测试直接调用输入法运行时使用的 `InputEngine`，覆盖四码不自动上屏、第五个字母保留预编辑、无候选英文、空格/回车提交、中英文连续混输、大小写及数字撇号、退格恢复候选、取消、数字选词、翻页边界、中文标点与引号、快捷键透传和切换输入法。另外使用原生 `NSEvent` 验证修饰键事件转换、左右 Shift 模式切换与组合键不误切换。拼音测试覆盖词频排序、全拼词组、音节分隔、三种模式互切及退格恢复候选。词库解析使用临时测试码表；本地有下载的主词库和拼音词库时还会验证真实词库样例。

构建脚本也会自动执行测试，因此从菜单重新构建加载时，测试失败会在停止旧输入法前中止更新。

词库合并和加载同样由 Swift 回归测试覆盖，包括组词规则、简码保护、统一词频、缺字跳过、确定性报告、用户词库添加与删除、运行时重载、设置切换、坏文件恢复、旧索引保留，以及原始文件不被修改。存在下载的真实词库时还会检查全部原词条保留与所有简码顺序。

系统集成和显示效果仍需安装后在 TextEdit、浏览器等应用中手动验证；这些自动测试不覆盖 InputMethodKit 通信、候选窗位置、字体渲染和通知。

使用已下载的五笔和袖珍拼音词库验证内存（包含首次加载、大前缀查询和重新加载；独立测试进程，不切换系统输入法）：

```bash
./scripts/profile-memory.sh
```

脚本输出 RSS 和物理内存占用，并检查物理占用不超过 128 MiB；可用 `WUBI_MEMORY_LIMIT_MB` 调整测试上限。系统版本和词库内容会影响实测值。

个人词频：确认候选后按词语累计使用次数，五笔、拼音及不同编码共享。精确匹配始终排在补全候选前面，两组内部各按个人次数降序排列，同次数保持词库原顺序；未使用时完全沿用词库顺序。回车原样提交、取消和切换模式不计数。选词只更新内存并重置 10 分钟计时器，连续 10 分钟没有确认候选后，在后台保存完整快照；退出或崩溃可能丢失尚未保存的计数。记录保存在 `~/Library/Application Support/Wubi/word-usage.json`，重启或重新加载词库后保留，不修改原始词库。
