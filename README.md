# 桃酥

macOS 原生五笔输入法，基于 Swift 与 Apple InputMethodKit，使用极点五笔 86 词库。支持全拼、手动造词和个人词频，无第三方运行时依赖，不需要辅助功能权限。

[安装](#安装) · [使用](#使用) · [个人词库](#个人词库) · [更新与卸载](#更新与卸载) · [开发文档](docs/development.md)

## 功能

- **五笔 86**：支持字词和前缀候选，四码唯一候选也由你确认后上屏。
- **全拼输入**：右 Shift 切换，拼音候选旁显示五笔码，方便查码。
- **手动造词**：输入汉字，即时列出拼音组合，双击保存，自动生成五笔词组码。
- **个人词频**：五笔四码和拼音候选按使用次数调整；一至三码保持原词库顺序。
- **中文标点**：支持成对引号，候选窗跟随系统浅色、深色外观。
- **本地用户数据**：词库和词频使用纯文本保存，可自行编辑和备份。

## 安装

### 从源码安装

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools：

```bash
xcode-select --install
```

下载或克隆本仓库后，在项目目录执行：

```bash
# 下载五笔和拼音词库
./get-dicts.sh
./get-pinyin-dict.sh

# 构建、测试并安装
./scripts/install-macos.sh
```

安装脚本会自动构建，安装位置为 `~/Library/Input Methods/Wubi.app`。

1. 注销并重新登录 macOS。
2. 打开「系统设置 → 键盘 → 文本输入 → 编辑 → + → 简体中文」。
3. 添加并切换到「桃酥」。

双击 `Wubi.app` 不能代替添加输入源。已安装的版本请按[更新说明](#更新与卸载)操作。

### 构建与分发

只构建、不安装：

```bash
./scripts/build-macos.sh
```

产物位于 `build/Wubi.app`。默认只构建当前 Mac 架构，使用本地临时签名；面向其他用户分发时，需要另行处理 Developer ID 签名和公证。

## 使用

### 按键

| 按键 | 功能 |
| --- | --- |
| 小写 `a`–`z` | 输入编码 |
| 单独按左 Shift | 英文直输 / 上次使用的中文模式 |
| 单独按右 Shift | 五笔 / 拼音；英文模式下进入拼音 |
| 空格 | 确认当前选中的候选 |
| `1`–`5` | 选择当前页对应候选 |
| ↑ / ↓ | 移动选择，到页边界自动跨页 |
| `,` / `.` | 上一页 / 下一页 |
| Backspace | 删除一个编码 |
| Escape | 取消当前编码 |
| Return | 原样提交编码 |

每页最多 5 个候选，当前选中项颜色较深。候选窗使用键盘选词，暂不支持鼠标点击。

### 五笔与拼音

五笔输入 `im`，可以提前选择「没有」，候选旁显示剩余编码 `de`。输入四码或第五个字母都不会自动上屏；没有候选时，编码留在编辑区，按空格或回车原样提交，Escape 取消。

拼音支持全拼字词，例如 `nihao` →「你好」、`zhongguo` →「中国」。可用撇号明确音节，如 `xi'an` →「西安」；`v` 表示 ü，如 `nv` →「女」。拼音候选旁显示对应的五笔码，优先显示简码，便于反查。

精确匹配排在补全候选前面。五笔与拼音分别查询词库；拼音不受五笔四码限制，目前不支持简拼、模糊拼音或词库之外的整句组词。

### 英文与中文标点

单独按左 Shift 进入英文直输，按键直接交给当前应用；再次按左 Shift 恢复中文。按住 Shift 输入大写或组合快捷键不会切换模式。切换模式时，未完成的编码会先原样提交。

中文模式默认转换标点。有候选时先确认当前选中词，再输入标点；逗号、句号优先用于翻页，需要输入它们时先选词。输入网址、小数等内容时，可切到英文模式或开启 Caps Lock。

<details>
<summary>中文标点对照</summary>

| 键盘字符 | 中文标点 |
| --- | --- |
| `, . ? ! : ;` | `，。？！：；` |
| `\` | `、` |
| `( ) [ ] < >` | `（）【】《》` |
| 双引号 / 单引号 | 交替输入 `“”` / `‘’` |
| `^` / `_` | `……` / `——` |
| `$` / `~` | `￥` / `～` |
| 反引号 | 保留英文反引号 `` ` ``，方便输入 Markdown 行内代码与代码围栏 |

中文引号输入后，会在光标附近短暂提示「左」或「右」。切换应用或输入法后，引号配对状态重置。

## 个人词库

### 手动造词

1. 在输入法菜单选择「手动造词」。
2. 在窗口中输入或粘贴汉字，下方即时显示所有可用拼音组合。
3. 双击正确的拼音，保存并关闭窗口。

造词窗口使用普通的系统输入框，可使用当前输入法输入。多音字组合较多时可滚动查看；未确认的编码不参与组词。输入框为单行，粘贴时去掉换行符。Escape 或关闭窗口可取消。

词条写入 `manual.txt`，保存后通知输入法重新加载，默认自动生成五笔编码。同词同拼音不重复保存，同词不同读音可分别保留；缺少单字读音时会提示对应汉字。

### 编辑与备份

菜单「打开用户词库目录」打开：

```text
~/Library/Application Support/Wubi/
├── manual.txt        # 用户添加词库
├── excluded.txt      # 可选排除词库
├── frequencies.txt   # 个人词频
├── settings.json     # 可选设置
└── tmp/              # 自动生成的报告和日志，可删除
```

备份 `manual.txt`、`excluded.txt`、`frequencies.txt` 以及自行创建的 `settings.json` 即可。`tmp/` 无需备份，删除后会在下次加载词库时重建。

`manual.txt` 使用 UTF-8，每行一个词条，词语和拼音之间用 **Tab** 分隔；支持空行和 `#` 注释：

```text
# 我的常用词
自定义词	zi ding yi ci
```

修改后点击「重新加载词库」即可生效，无需重新构建。删除词条后同样操作；文件格式错误时会跳过用户词库，并保留内置词库可用。

`excluded.txt` 使用 UTF-8，每行一个完整词语，支持空行和 `#` 注释：

```text
# 排除不需要的词条
高的
高高的
更高的
```

保存后点击「重新加载词库」，即可从五笔和拼音中同时排除这些词，包括所有编码、读音、补全候选及反查结果。排除规则优先于内置词库和 `manual.txt`，被排除的词不会参与自动补词；只匹配完整词语，不影响包含该词的其他词语。删除对应行并重新加载即可恢复。文件不存在时不排除任何词；文件无法读取时保留此前的运行时词库，并记录错误。

`frequencies.txt` 每行记录 `词语<Tab>使用次数`。选词时自动累计，五笔和拼音共享记录；仅五笔四码和拼音参与调频，精确候选始终排在补全候选前面。相同次数保留词库顺序，无效记录跳过，同词重复记录取最大正整数次数。

保存词频时会读取当前 `excluded.txt`，从 `frequencies.txt` 中删除被排除词的记录；只匹配完整词语。排除文件无法读取时取消本次保存，保留原词频文件。

**词频在连续 10 分钟没有选词后才保存。** 重启、退出或崩溃前尚未写入磁盘的计数可能丢失，包括菜单中的重新构建操作。

### 五笔词库补充

默认将拼音词库中五笔尚未收录的汉字词语补入五笔词库，个人词条也参与生成：

| 词长 | 五笔组词规则 |
| --- | --- |
| 两字 | 各取前两码 |
| 三字 | 前两字各取首码，第三字取前两码 |
| 四字及以上 | 第一、第二、第三及最后一字各取首码 |

单字采用最长编码；缺少单字编码或包含非汉字的词跳过。已有词不额外生成新编码。

如需关闭补充功能，在用户数据目录的 `settings.json` 中写入以下内容，再点击「重新加载词库」：

```json
{"mergePinyinIntoWubi": false}
```

关闭后，新增个人词条只加入拼音词库。删除该设置或改成 `true` 可恢复。

## 更新与卸载

修改代码或更新内置词库后，在项目目录执行：

```bash
./scripts/reload-macos.sh
```

也可点击输入法菜单「重新构建并加载输入法」。更新过程会先构建并测试新版本，再重启输入法；失败时尝试回退。运行前请先完成正在输入的编码。菜单更新依赖构建时的源码目录，目录移动后需重新构建安装。

| 操作 | 适用情况 |
| --- | --- |
| 重新加载词库 | 修改 `manual.txt` 或 `settings.json` |
| 重新构建并加载输入法 | 修改源码或内置词库 |

更新日志位于 `~/Library/Logs/Wubi/reload.log`。首次安装或修改输入源注册信息后，仍可能需要注销登录。

卸载时，先在系统设置中移除「桃酥」输入源，再删除 `~/Library/Input Methods/Wubi.app`，最后注销登录。用户数据单独保留，可自行备份或删除。

## 常见问题

**安装后找不到输入源？** 先注销并重新登录，再到「简体中文」分类添加「桃酥」。直接启动 app 不会完成输入源注册。

**用户词条没有生效？** 确认保存到 `manual.txt`，词语和拼音之间使用 Tab，并点击「重新加载词库」。若拼音可输入而五笔不可输入，检查是否关闭了自动补充，或某个字缺少五笔编码。详细原因见 `tmp/dictionary-load-issues.log` 和 `tmp/dictionary-merge-report.md`。

**菜单更新失败？** 查看 `~/Library/Logs/Wubi/reload.log`，确认本机源码目录仍存在、构建测试能通过。系统通知可能受通知设置或专注模式影响。
