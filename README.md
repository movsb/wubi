# WUBI

基于 Swift 和 Apple InputMethodKit 的 macOS 原生五笔输入法。

## macOS 输入法

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools（`xcode-select --install`）。无第三方运行时依赖。默认构建当前 Mac 架构，使用本地临时签名，适合本机使用；对外分发需另行 Developer ID 签名和公证。

```bash
./get-dicts.sh
./scripts/build-macos.sh
./scripts/install-macos.sh
```

安装到 `~/Library/Input Methods/Wubi.app`。首次安装后注销并重新登录，在「系统设置 → 键盘 → 文本输入 → 编辑 → + → 简体中文」中添加「五笔」。不需要辅助功能权限。仅构建时，产物位于 `build/Wubi.app`；双击 app 不会代替输入源注册。

词库沿用 [极点五笔 86 词库](https://github.com/KyleBing/rime-wubi86-jidian)，下载文件不提交到仓库。构建时打包根目录下的全部 `*.dict.yaml`，至少需要主词库 `wubi86_jidian.dict.yaml`。支持两列或带权重的多列 Rime 码表，按权重降序排列，同权重保留码表顺序，重复词条去重。扩展及用户词库可按需删除后重新构建。使用和分发词库时请查看上游的许可说明。

| 按键 | 功能 |
| --- | --- |
| 小写 a–z | 输入五笔编码 |
| 空格 | 上屏当前选中的候选词，默认首选词 |
| 1–9 | 选择当前页候选词 |
| 上下方向键 | 逐个切换候选词，可跨页 |
| 左右方向键、Page Up/Down、- / = | 候选翻页 |
| Backspace | 删除一个编码 |
| Escape | 取消当前编码 |
| Return | 原样输入编码 |
| 四码唯一候选 | 保留候选，按空格或数字选词上屏 |
| 无候选编码或超过四个字母 | 保留全部预编辑文本，空格或回车原样上屏 |

候选窗目前支持键盘选词，不支持鼠标点击。Shift 大写字母作为英文预编辑文本输入，Caps Lock 与常用系统快捷键交给应用处理。暂未实现拼音反查、学习调频及设置面板。候选只匹配完整编码，保留原程序行为。

默认首个候选词深色显示，其余候选词为浅色；上下键移动选择时，深色随当前选中词移动。空格确认选择，数字键仍按当前页编号直接选词；回车仍提交原始编码。

所有字母都累积在编辑框的预编辑文本中，不因输入第五个字母而自动上屏。无候选或超过四个字母时隐藏候选窗，后续数字、撇号等英文字符也保留在预编辑文本中；空格或回车提交英文原文，该按键只用于确认，不额外插入空格或换行。提交后立即可以输入下一段五笔。退格后重新匹配候选，Escape 取消整段预编辑文本。

默认输入中文标点；存在有效候选时，先上屏当前页首选词，再输入标点；无候选时英文标点保留在预编辑文本中。Caps Lock 开启时保留英文标点，Command、Control、Option 快捷键不转换。

| 键盘字符 | 中文标点 |
| --- | --- |
| `, . ? ! : ;` | `，。？！：；` |
| `\` | `、` |
| `( ) [ ] < >` | `（）【】《》` |
| 双引号 / 单引号 | 交替输入 `“”` / `‘’`，切换应用或输入法后重置 |
| `^` / `_` | `……` / `——` |
| `$` / `~` / 反引号 | `￥` / `～` / `·` |

输入中文引号后，光标附近会显示「左」或「右」，单、双引号均适用，约 0.8 秒后消失。继续按键或切换输入法会立即关闭提示，不抢焦点，不向正文插入提示文字；英文预编辑中的撇号不提示。

`-` 和 `=` 在有候选时仍用于翻页，其余字符保留原样。输入小数、网址等英文内容时可开启 Caps Lock 或切换英文输入源。

日常修改代码或词库后，运行以下命令更新，无需注销：

```bash
./scripts/reload-macos.sh
```

脚本先构建，临时切换到备用键盘，停止五笔进程，更新 app，再启动并恢复原输入源。运行前请先完成正在输入的编码；进程重启会清空未完成的输入。这是重启更新，不是进程内热加载。首次安装或修改输入源注册信息后，仍可能需要注销登录。

也可以在选中五笔时，点击菜单栏输入法菜单中的「重新构建并加载输入法」。菜单按钮会后台运行同一更新脚本，新版本启动并恢复输入源后发送「五笔重新加载成功」系统通知，无需点击关闭。通知是否显示受系统通知设置和专注模式影响。日志写入 `~/Library/Logs/Wubi/reload.log`。此开发功能依赖构建时的本机源码目录；目录移走后需在新位置重新构建安装。

卸载时先从系统设置移除输入源，再删除 `~/Library/Input Methods/Wubi.app`，注销登录。

运行回归测试（无需安装输入法，无需下载词库）：

```bash
./scripts/test.sh
```

测试直接调用输入法运行时使用的 `InputEngine`，覆盖四码不自动上屏、第五个字母保留预编辑、无候选英文、空格/回车提交、中英文连续混输、大小写及数字撇号、退格恢复候选、取消、数字选词、翻页边界、中文标点与引号、快捷键透传和切换输入法。词库解析使用临时测试码表；本地有主词库时还会验证真实词库样例。

构建脚本也会自动执行测试，因此从菜单重新构建加载时，测试失败会在停止旧输入法前中止更新。

系统集成和显示效果仍需安装后在 TextEdit、浏览器等应用中手动验证；这些自动测试不覆盖 InputMethodKit 通信、候选窗位置、字体渲染和通知。
